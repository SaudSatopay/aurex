# Third-party UI components

Components in this folder are adapted from the libraries below and used as part of AUREX, the
application. Each file names its source in a header comment. They were ported from the adaptations in
the ORCA project, restyled to AUREX's tokens and rewritten for React 19 and Tailwind 4; they are not
offered for reuse outside this project.
